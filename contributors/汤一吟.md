# 汤一吟

## 负责方向

操作系统知识在 MiniDB 数据库系统中的实践与验证。

## 主要工作

- 学习并整理操作系统中的文件管理、随机 I/O、内存缓存、互斥同步和持久化等知识，分析这些原理在数据库存储系统中的具体应用。
- 围绕 `storage/page.py` 学习和验证固定大小页文件的实现：每个页面为 4096 字节，通过 `page_id * PAGE_SIZE` 计算文件偏移，并使用 `seek()` 完成页面随机读写。
- 整理页面分配、释放和空闲页复用流程，验证 `.free` 文件对空闲页列表的持久化，以及临时文件配合 `os.replace` 更新元数据的可靠性。
- 分析页面写入过程中的长度校验、JSON 负载编码、文件越界检查、`flush()` 和 `os.fsync()`，理解用户态缓冲、操作系统文件缓存和数据库持久化之间的关系。
- 围绕 `storage/buffer_pool.py` 验证数据库缓冲池的工作流程：缓存命中与未命中、磁盘读写统计、LRU/FIFO 页面替换、Pin 页面保护、脏页标记和刷回磁盘。
- 分析缓冲池使用 `(文件路径, page_id)` 区分页面的原因，避免不同表文件中相同页号发生冲突；整理容量不足、所有页面被 Pin 等异常情况的处理方式。
- 学习 `RLock` 在页面分配、释放和读写中的作用，理解多线程访问共享文件和缓存结构时的互斥保护，以及可重入锁解决嵌套调用加锁问题的原因。
- 跟踪 SQL 执行到物理存储访问的调用链，理解 `PlanExecutor`、`TableHeap`、`BufferPool` 和 `PageManager` 之间的协作，使操作系统知识与数据库查询执行过程对应起来。
- 配合小组完成页式存储、缓冲池统计、数据文件读写、页面回收复用和异常输入等功能的测试与结果整理，并协助编写答辩和实验说明材料。

## 实践与验证内容

- 验证固定页文件的页面数量始终等于文件字节数除以 4096，页面越界、短页读取和负页号能够被正确识别。
- 验证释放页面后再次分配时优先复用空闲页，且不会错误覆盖其他页面的数据。
- 使用不同缓冲池容量和 `LRU`/`FIFO` 策略观察命中、未命中、淘汰、磁盘读写和脏页刷回统计。
- 验证被 Pin 的页面不能被淘汰或删除，页面解除 Pin 后才能参与替换。
- 结合数据库的 `SELECT`、`INSERT`、`UPDATE` 和 `DELETE` 流程，观察逻辑数据如何经过页式存储和缓冲池访问磁盘文件。

## 个人收获

通过本项目，我将操作系统中的文件、I/O、缓存和同步知识与数据库系统的页式存储实现联系起来，理解了数据库如何把表和记录组织成磁盘页面，并通过内存缓冲池减少磁盘访问。同时，我进一步掌握了固定大小文件页、脏页持久化、页面替换、空闲空间复用和线程安全访问等实际工程问题。
