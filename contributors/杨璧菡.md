# 杨璧菡

负责模块：执行引擎、存储引擎、Catalog 和前端

完成内容：

- 负责执行引擎的整体编排：完成 SQL 编译结果到物理执行计划的衔接，并支持顺序扫描、索引扫描、过滤、连接、聚合、排序、LIMIT/OFFSET 等算子的递归执行。
- 负责执行过程中的数据读取、行级锁、事务可见性和执行指标采集，支持结构化结果输出以及 `EXPLAIN ANALYZE` 所需的执行信息。
- 负责存储引擎的页管理、Buffer Pool、RID/槽页表堆和行编码，支持 LRU/FIFO 页面淘汰、Pin 防淘汰、脏页刷回、缓存命中统计和数据持久化。
- 负责 Catalog 的分页持久化：保存表结构、列定义、数据页列表、索引信息、用户和权限，并支持从旧版 `catalog.json` 迁移到 `catalog.dat`。
- 负责前端控制台和 JSON API 的联调，实现 SQL 执行、结果表格展示、执行计划查看、Buffer Pool 指标、缓存冷热对比以及多标签页会话管理。
- 配合完成执行引擎、存储引擎、Catalog 与前端之间的接口联调和功能验证。

- `engine/database.py`、`engine/executor.py`、`engine/operators.py`
- `storage/page.py`、`storage/buffer_pool.py`、`storage/table_heap.py`、`storage/slotted_page.py`、`storage/row_codec.py`
- `catalog/paged_catalog.py`
- `web/server.py`、`web/studio.js`、`web/studio.html`
